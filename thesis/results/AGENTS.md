# results/ — Measured Facts

## Purpose

Hold measured outcomes as facts: metrics, tables, and comparisons tied to a run ID.

## Ownership

- Authoritative for measured numbers.

## Local Contracts

- YAML front matter on every doc.
- Every number must trace to an experiment record and run ID.
- No interpretation or recommendations; keep those out.
- Prefer tables with explicit units and evaluation protocol.

## Work Guidance

- Baseline results are generated by `scripts/document_results.py` from `runs/` metrics.
- Baseline error-analysis facts are in `baseline-error-analysis.md`; raw data stays in `runs/eval/<run>/error_analysis/`.
- Curated figures live in `thesis/results/figures/`; full plots stay in `runs/`.
- VRAM values must be labeled as training-PyTorch, training-GPU-used, or inference.

## Verification

- No automated checks.
